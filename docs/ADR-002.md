# ADR-002: Tauri window Wayland fallback

Date: 2026-10-02. Status: accepted.

Context: `alwaysOnTop` unreliable on Wayland (upstream); transparent windows can crash on Nvidia+WebKitGTK.

Decision: ship `transparent + decorations:false + alwaysOnTop` as default (proven working on this Hyprland machine); if compositor misbehaves, degrade gracefully: opaque background first, then drop always-on-top, never crash. No `wlr-layer-shell` custom code in MVP.

Consequences: z-order/transparency best-effort on Wayland; settings expose opacity/on-top toggles (Phase 6).
