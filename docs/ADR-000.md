# ADR-000: npm for TypeScript workspaces

Date: 2026-10-02. Status: accepted.

Context: master prompt specifies pnpm workspaces. This machine has Node 26 + npm, no pnpm.

Decision: use npm workspaces for all TS packages (`apps/desktop`, `packages/opencode-plugin`, `packages/protocol`).

Consequences: one less tool to install; slower installs accepted for MVP. Revisit if install times hurt CI.
