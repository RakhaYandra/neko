# ADR-001: Unix Domain Socket IPC, no TCP in MVP

Date: 2026-10-02. Status: accepted.

Context: plugin must deliver events to Neko core locally with minimal attack surface.

Decision: NDJSON over Unix Domain Socket, mode `0600`, one connection per message, fire-and-forget (`|| true`) so agent never blocks. No TCP listener.

Consequences: local-only by construction; Neko death never affects OpenCode (proven T4). Multi-host out of scope.
