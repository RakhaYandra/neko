# ADR-003: versioned protocol envelope

Date: 2026-10-02. Status: accepted.

Context: OpenCode event names are upstream-controlled; Neko needs a stable contract.

Decision: every socket message is `{"v":1,"type":"<neko.type>","at":<ms>, ...payload}`. Receivers reject unknown `v` and malformed JSON without dying. Never mirror OpenCode names 1:1; adapt in plugin. Zod schemas live in `packages/protocol` (Phase 1+).

Consequences: protocol can evolve (`v:2`) with explicit migration; plugin and core validate independently.
